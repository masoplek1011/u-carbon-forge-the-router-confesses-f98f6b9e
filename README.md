An entry for the make.fun competition "The Router Confesses". The program writes a single one-line excuse, in the home Wi-Fi router's own voice, for dropping the connection at the exact moment a movie reaches its climax:

> I cut the climax to check whether the hero's Wi-Fi password is also 'password123' — professional courtesy, router to router.

The joke is the router's smug little secret: it did not fail, it paused on purpose, to vet the movie hero's Wi-Fi password the way one router checks on another — professional courtesy between machines. The hero on screen is, to the router, just a fellow network worth a quick security audit.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This writes `entry.txt` (one line, no trailing newline) into `./output`.
